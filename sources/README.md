# sources/ (private)

Raw inputs. **Everything in this folder except this README is git-ignored** and never published (PROJECT_INSTRUCTIONS.md §3).

| Folder | What's in it |
|---|---|
| `docs/` | Original drafts: the WMD tour (`UK WMD Tour - Fleshed OUt.docx`), the office restaurant and pub list (`London Restaurants.docx`), and the OneNote PDF export that combines both |
| `google-maps/saved/` | All Google Takeout "Saved" lists (the triage drew on UK 2023, Pubs, London Historic Restaurants and Pubs, Espionage History, UK Seafood and a few others; the rest are other countries and personal lists) |
| `google-maps/takeout/` | Our Google reviews (`Reviews.json`), starred and labelled places, and My Maps exports (London Football Teams and others) |
| `google-maps/archives/` | The original Takeout zip files |
| `triage/google-maps-triage.csv` | **The Google Maps triage results** (the canonical copy, after the 2026-10-03 review): 503 rows with decision, proposed type, themes and badge, notes, scope and area. Theme sessions start here. Kept private because it holds our saved-place history |
| `NHLE...csv` | Historic England's National Heritage List (listed buildings), for fact-checking dates and listings |

Some list names and rows identify us or where we live. Never quote list names, notes or addresses from here into `content/` or `planning/`.

Everything that used to live in the OneDrive `London-Guide` folder is now here; that folder is only an archive.
